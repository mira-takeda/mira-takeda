## Selected projects

### Tiny Learner

**Learn. Remember. Adapt.**

A compact, CPU-first learning agent investigating skill acquisition, retention, and transfer to unfamiliar task combinations.

*Meta Global AI Developer Hackathon 2026 · Active development*

### SEMILLA

Independent experimental research into how small adaptive systems learn from consequences, detect changes in their environment, and revise strategies when earlier assumptions stop working.

*Learning mechanisms · Consequence-based learning · Adaptation*

### IRIA & XILA

Two experimental agents sharing a simulated environment, with alternating actor and observer roles. The project explores learning from ongoing interaction, observation, and each agent's own experience.

*Paired agents · Shared environments · Continuous experience*

---

## Research direction

These projects explore different questions rather than serving as successive versions of the same system.

The common interest is building **small systems that can change through experience**, and investigating when those changes produce useful behavior.
